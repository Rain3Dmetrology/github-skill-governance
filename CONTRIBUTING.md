# Contributing

Thank you for helping build a portable, evidence-driven governance stack for
agent skills.

## Before contributing

1. Read `.github/governance/repo-policy.yaml` and the accepted ADRs.
2. Do not copy code or prose from the BSL-licensed legacy repository.
3. Record every incorporated third-party source in `THIRD_PARTY_NOTICES.md`.
4. Keep one pull request focused on one governance or implementation outcome.
5. Add evidence for every new `implemented` claim.

## Change discipline

- P0 changes are policy and documentation only.
- Release automation, AI reviewers, GitHub Apps, tokens, and write-capable MCP
  tools are out of scope until their later phase is accepted.
- Never commit credentials, internal customer identifiers, or private paths.
- After the initial bootstrap, use pull requests rather than direct pushes.
