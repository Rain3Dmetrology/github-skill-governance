# Third-Party Notices

## P0 independent-rewrite baseline

No third-party source code, Skill text, README text, or release script was
deliberately copied from `Rain3Dmetrology/github-release-management` into this
repository.

The prior repository was used only to identify requirements, risks, and
failure scenarios. Those ideas were independently expressed in this
repository's governance records.

This notice is a process record, not a formal legal clean-room certification.
See [`docs/provenance/P0_SOURCE_LOG.md`](./docs/provenance/P0_SOURCE_LOG.md) for
the reviewed inputs, exclusions, drafting method, and limitations.

The Apache License 2.0 text in `LICENSE` is the standard license text.

Every future contribution that incorporates third-party material must record:

1. upstream project and canonical URL;
2. exact tag or commit SHA;
3. original license and compatibility decision;
4. files or portions incorporated;
5. local modifications and required notices.

Unknown provenance blocks release. Discovery links and design inspiration do
not authorize copying protected text or code.
